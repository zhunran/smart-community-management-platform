# 物业管理系统 - 技术栈

## 一、后端技术栈

### 核心框架

| 技术        | 版本  | 说明                                                                                                           |
| ----------- | ----- | -------------------------------------------------------------------------------------------------------------- |
| Spring Boot | 4.1.0 | 基于 Spring Framework 7.x / Jakarta EE，新一代 Spring Boot                                                     |
| JDK         | 25    | 通过 `maven-compiler-plugin` 的 `--release 25` 编译                                                            |
| Maven       | 3.x   | 多模块聚合项目构建                                                                                             |
| Spring AOP  | -     | AOP 切面支持（`spring-aop` + `aspectjweaver`），Spring Boot 4.x 已移除 `spring-boot-starter-aop`，改为直接依赖 |

### 数据层

| 技术                    | 版本   | 说明                                                        |
| ----------------------- | ------ | ----------------------------------------------------------- |
| MyBatis-Plus            | 3.5.16 | 专用于 Spring Boot 4 的 `mybatis-plus-spring-boot4-starter` |
| MyBatis-Plus JSqlParser | 3.5.16 | 分页插件 SQL 解析                                           |
| MySQL                   | 8.x    | 关系型数据库，JDBC 驱动 `mysql-connector-j`                 |
| H2 Database             | -      | 测试环境使用（payment 模块 test scope）                     |

### 缓存

| 技术         | 版本 | 说明                                                      |
| ------------ | ---- | --------------------------------------------------------- |
| Redis        | 7.x  | 通过 Spring Data Redis + Lettuce 连接池访问               |
| Spring Cache | -    | `@Cacheable` / `@CacheEvict` 注解式缓存，默认 TTL 30 分钟 |

### 鉴权与安全

| 技术                   | 版本   | 说明                                                  |
| ---------------------- | ------ | ----------------------------------------------------- |
| JJWT                   | 0.12.5 | jjwt-api + jjwt-impl + jjwt-jackson，HMAC-SHA512 签名 |
| Spring Security Crypto | 6.2.4  | BCrypt 密码加密（锁定 6.x 版本兼容 hash 格式）        |

### API 文档与接口

| 技术                | 版本   | 说明                                                                                           |
| ------------------- | ------ | ---------------------------------------------------------------------------------------------- |
| Knife4j             | 5.0.18 | 社区 fork 版（`com.baizhukui:knife4j-openapi3-boot4-spring-boot-starter`），兼容 Spring Boot 4 |

## 三、基础设施

| 组件           | 说明                                                    |
| -------------- | ------------------------------------------------------- |
| MySQL          | 关系型数据库，存储所有业务数据（`property_management`） |
| Redis          | 缓存（系统配置、Token 黑名单、Refresh Token）、分布式锁 |
| Nginx          | 反向代理，前端静态资源托管                              |
| Docker Compose | 容器编排，一键启动所有服务                              |
| XXL-Job Admin  | 分布式任务调度中心（端口 9099）                         |
