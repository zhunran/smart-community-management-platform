# 基础八股清单（通用 Java 后端面试高频考点）

> 与《项目核心八股.md》区分：这份是**脱离项目的通用高频考点**，按面试出现频率分权重排序。
> 分层标准：**P0 必考**（出现频率极高，决定基础分）→ **P1 高频**（大概率被问）→ **P2 中低频**（看面试官风格与岗位要求）。
> 用法：P0 逐条吃透到"能口述原理 + 能画图 + 能举例"，P1 讲清主线，P2 有余力再看。

---

## 🔴 P0：必考，出现频率最高（占面试 60%+）

### 1. Java 基础

| 考点 | 核心要点与典型问法 |
|---|---|
| **HashMap** | 底层数组+链表/红黑树、put 流程、扩容、为什么链表长度 8 转红黑树、负载因子 0.75、JDK7/8 区别、头插尾插 |
| **HashMap vs ConcurrentHashMap** | 1.7 分段锁 vs 1.8 CAS+synchronized、为啥线程不安全、putIfAbsent |
| **ArrayList vs LinkedList** | 底层、扩容（1.5 倍）、随机访问/插入删除复杂度、为啥 ArrayList 用 size 记录长度 |
| **String 不可变** | 为什么不可变、常量池、`String a = new String("x")` 创建几个对象、StringBuilder 线程不安全 vs StringBuffer |
| **== 与 equals / hashCode** | 重写 equals 必须重写 hashCode、典型 bug、hashCode 约定 |
| **异常体系** | Error/Exception、运行时异常 vs 受检异常、finally 执行时机、try-with-resources |
| **反射** | 原理、优缺点、应用（框架、动态代理）、Class 对象的获取方式 |
| **泛型与类型擦除** | 为什么擦除、桥方法、`List<String>` 为何能 add Integer（运行时）、`? extends` / `? super` 上下界 |
| **接口 vs 抽象类** | 区别、JDK8 默认方法、何时用哪个 |
| **深拷贝 vs 浅拷贝** | 实现方式、clone 与序列化 |

### 2. JVM

| 考点 | 核心要点与典型问法 |
|---|---|
| **运行时数据区** | 堆/栈/方法区/程序计数器/本地方法栈、各存什么、线程共享 vs 私有 |
| **对象创建与内存分配** | new 的完整流程、对象头、指针碰撞/空闲列表、TLAB |
| **类加载机制** | 加载/链接/初始化、双亲委派模型、为什么这么设计、如何打破（SPI、Tomcat） |
| **GC 判断对象存活** | 可达性分析、GC Roots 有哪些、finalize 未死 |
| **垃圾回收算法** | 标记清除/复制/标记整理、分代收集、各代用什么算法 |
| **垃圾回收器** | Serial/Parallel/CMS/G1/ZGC、G1 原理、如何选择 |
| **OOM 与排查** | 哪些类型 OOM（堆/栈/MetaSpace/直接内存）、排查命令 jps/jmap/jstat/jstack、内存泄漏 vs 溢出 |

### 3. 并发编程（JUC）—— 权重最高的子领域

| 考点 | 核心要点与典型问法 |
|---|---|
| **synchronized** | 锁升级（无锁→偏向锁→轻量锁→重量锁）、底层 monitor、可重入、与 Lock 区别 |
| **ReentrantLock** | AQS 原理、公平/非公平、Condition、可打断/超时 |
| **volatile** | 可见性/有序性（内存屏障）、不保证原子性、happens-before、单例双重检查为什么加 volatile |
| **CAS** | 原理、ABA 问题、原子类（AtomicInteger）、LongAdder 优化 |
| **线程池** | 七大参数、执行流程、四种内置线程池问题、拒绝策略、为什么禁止 Executors 创建 |
| **ThreadLocal** | 原理（ThreadLocalMap）、key 弱引用、内存泄漏原因与解决方法 |
| **死锁** | 四个必要条件、排查（jstack）、如何避免（加锁顺序） |
| **wait/notify vs park/unpark** | 与 synchronized 配合、虚假唤醒、Condition 区别 |
| **AQS 原理** | state、CLH 队列、独占/共享模式 |

### 4. MySQL

| 考点 | 核心要点与典型问法 |
|---|---|
| **索引** | B+ 树 vs B 树 vs 哈希、聚簇/非聚簇、覆盖索引、最左前缀、索引失效场景、回表、联合索引设计 |
| **explain** | type 字段（const/ref/range/index/all）、key、rows、Extra（Using index/Using filesort/Using temporary） |
| **事务 ACID** | 各是什么、靠什么实现（redo/undo/MVCC/锁） |
| **隔离级别** | 四种级别、脏读/不可重复读/幻读、InnoDB 默认 RR |
| **MVCC** | 版本链、ReadView、快照读 vs 当前读、怎么解决不可重复读 |
| **锁** | 行锁/表锁、共享锁/排他锁、间隙锁/临键锁、死锁、乐观锁 vs 悲观锁 |
| **SQL 优化** | 慢查询定位、避免 select *、大字段、排序分页优化、深分页 |
| **分库分表** | 水平/垂直、分片键、一致性哈希、扩容问题 |

### 5. Redis

| 考点 | 核心要点与典型问法 |
|---|---|
| **数据结构** | String/Hash/List/Set/ZSet 底层（SDS、zipList、quickList、跳表）、使用场景 |
| **为什么快 / 单线程** | 内存、IO 多路复用、单线程避免锁竞争、6.0 后多线程处理网络 |
| **持久化** | RDB vs AOF、AOF 重写、混合持久化、数据丢失窗口 |
| **过期删除与淘汰** | 惰性删除+定期删除、内存淘汰策略（LRU/LFU）、maxmemory |
| **缓存三兄弟** | 穿透（布隆过滤器/空值）、击穿（互斥锁/热点不过期）、雪崩（TTL 随机/多级缓存） |
| **缓存一致性** | 先删缓存还是先更新 DB、延迟双删、Cache Aside、最终一致 |
| **分布式锁** | SET NX EX、Lua 原子释放、看门狗续期、RedLock、可重入 |

### 6. Spring 全家桶

| 考点 | 核心要点与典型问法 |
|---|---|
| **IoC** | 控制反转/依赖注入、BeanFactory vs ApplicationContext、Bean 生命周期 |
| **Bean 作用域** | singleton/prototype/request/session、单例 Bean 线程安全 |
| **Bean 生命周期** | 实例化→属性填充→初始化→销毁、Aware 接口、BeanPostProcessor |
| **AOP** | 原理、JDK 动态代理 vs CGLIB、切面/切点/通知、失效场景 |
| **循环依赖** | 三级缓存、为什么三级、哪些循环依赖解决不了（构造器注入） |
| **事务** | 传播行为、隔离级别、失效场景（自调用/非 public/异常被吞）、事务嵌套 |
| **SpringMVC 流程** | DispatcherServlet 处理流程、参数绑定、HandlerMapping/Adapter |
| **SpringBoot 自动装配** | @SpringBootApplication、@EnableAutoConfiguration、条件注解原理 |

## 复习优先级速查

```
必须先吃透（P0）：HashMap / ConcurrentHashMap → 线程池 → volatile/CAS/synchronized → MySQL 索引与事务 → Redis 缓存三兄弟 → Spring Bean 生命周期与循环依赖 → AOP → 事务失效

次优先（P1）：TCP 握手挥手 → HTTPS → MyBatis 缓存 → 设计模式单例 → MQ 消息可靠性 → IO 模型

加分项（P2）：分布式事务/ID → 系统设计（秒杀/短链）→ Linux/Docker 排查
```

> 建议：P0 每个考点要求**能口述 + 能画图 + 能举例 + 能讲清边界场景**，P1 讲清主线，P2 按目标岗位（是否微服务/高并发）选择性深入。
