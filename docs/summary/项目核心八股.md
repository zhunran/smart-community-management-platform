## 🔴 P0：项目直接关联，必须到L4（扛追三层）

### 1. 并发与锁（你的支付模块是“弹药库”）

| 八股考点 | 你的项目对应点 | 面试官会怎么问 |
|---|---|---|
| **synchronized 锁升级** | 支付回调三层防护：Redis分布式锁 + `FOR UPDATE` + 乐观锁 | “为什么同一个回调要叠三层锁？每一层解决什么问题？只留一层会出什么问题？” |
| **ThreadLocal 内存泄漏** | `SecurityUtil` 用 ThreadLocal 存用户信息，`AuthInterceptor` 在 `afterCompletion` 清理 | “你的用户上下文是怎么存的？为什么请求结束要清理？不清理会怎样？” |
| **Redis 分布式锁（SET NX EX）** | `RedisUtil.tryLock()` 用 `SET NX EX`，`unlock()` 用 Lua 脚本 | “为什么用 SET NX EX 而不是先 SETNX 再 EXPIRE？释放锁为什么必须用 Lua 脚本？” |
| **乐观锁 vs 悲观锁** | 支付回调用乐观锁（`WHERE status=?`）兜底，账单查询用 `FOR UPDATE` 悲观锁 | “你的项目里哪里用了乐观锁，哪里用了悲观锁？为什么这样选？” |
| **死锁** | 缴费场景：多笔回调同时分摊，若加锁顺序不一致可能死锁 | “什么操作顺序会触发死锁？你的项目里怎么避免？” |
| **volatile** | 无直接对应点：异步日志用单线程守护线程池，本身就规避了可见性/竞态问题，可反向说明“为什么要单线程” | “为什么异步日志用单线程就够了？若改成多线程，volatile 能保证什么、不能保证什么（原子性）？” |

### 2. MySQL（你的统计模块、分页查询、账单表全勾得上）

| 八股考点 | 你的项目对应点 | 面试官会怎么问 |
|---|---|---|
| **B+ 树索引** | 账单表 `t_bill` 按 `due_date` + `status` 查询 | “账单逾期扫描的 SQL 怎么写？`due_date` 和 `status` 联合索引怎么建？最左前缀怎么用？” |
| **事务隔离级别** | 支付回调在 `PaymentCallbackTxService` 里 `@Transactional(rollbackFor = Exception.class)`，未显式配置隔离级别（InnoDB 默认 REPEATABLE READ） | “你的支付回调用的是什么隔离级别？RR 下 `FOR UPDATE` 会锁记录还是间隙？” |
| **MVCC** | 缴费场景：A 缴费时 B 查询同一张账单 | “两个事务同时操作同一张账单，MVCC 怎么保证读不阻塞写？” |
| **行锁 / 间隙锁** | `selectByIdForUpdate` 的行锁机制 | “`FOR UPDATE` 在 RR 隔离级别下，锁的是记录还是间隙？什么情况下会升级为表锁？” |
| **慢 SQL 优化** | 统计模块的聚合查询、审计日志的 Top10 查询 | “如果审计日志一年几千万条，统计 Top10 模块的查询会多慢？你怎么优化？” |
| **深分页** | `PageQuery` + MyBatis-Plus 分页 | “`offset=100000` 时为什么慢？你的项目里怎么优化？” |

### 3. Spring（你的 framework 模块全是 Spring 的“教科书案例”）

| 八股考点 | 你的项目对应点 | 面试官会怎么问 |
|---|---|---|
| **IoC 与 Bean 生命周期** | 你的 `JacksonConfig`、`RedisConfig`、`AuthInterceptor` 全是 Bean | “Spring 怎么管理你的拦截器？Bean 从创建到销毁经历了哪些阶段？” |
| **AOP 原理（JDK 动态代理 vs CGLIB）** | `WebLogAspect`、`OperationLogAspect` 用 `@Around` 切面 | “你的日志切面底层是怎么实现的？为什么 `@Cacheable` 内部调用会失效？” |
| **@Transactional 失效** | 两处案例：① `SysConfigService` 的 `@Cacheable` 内部调用，用 `@Lazy` 自注入解决；② 支付模块用独立的 `PaymentCallbackTxService`/`PaymentReconciliationTxService` 事务类规避自调用失效 | “为什么 `this.method()` 会绕过代理？`@Cacheable` 与 `@Transactional` 失效是同一根因吗？分别用了哪两种技巧解决？” |
| **Spring MVC 请求流程** | `TraceFilter` → `AuthInterceptor` → Controller → `ResponseAdvice` | “从请求进来到响应出去，你的项目里经过了哪些组件？顺序是什么？” |
| **HttpMessageConverter** | 你踩过的坑：Jackson `Long → String` 序列化不生效 | “你当时怎么排查的？为什么自定义的 ObjectMapper 没生效？后来怎么解决的？” |
| **三级缓存与循环依赖** | 你的模块之间单向依赖，未出现循环依赖 | “如果 A 和 B 互相依赖，Spring 怎么用三级缓存解决？为什么是三级不是两级？” |

### 4. Redis（你的项目里 Redis 身兼数职）

| 八股考点 | 你的项目对应点 | 面试官会怎么问 |
