## 依赖关系

```
Day1 ──→ Day2 ──→ Day3 ──→ Day5 ──→ Day7
  │                        │
  └──→ Day4 ──────────────→┘    Day6 ──→ Day7
                                    │
                                    └── （Day5/6 可并行）

Day7 ──→ Day8 ──→ Day9 ──→ Day10 ──→ Day12
                              │
                              Day11 ──→ Day12
                               │
                               └── （Day10/11 可并行）
```

**说明**：
- Day 2 和 Day 4 在后端层面可并行（两个模块独立），但共享 Day 1 的骨架
- Day 5 和 Day 6 可并行（管理端与业主端独立）
- Day 10 和 Day 11 可并行
- 若单人开发无需并行，按顺序执行即可

## 风险提醒

| 风险                        | 影响天 | 应对                                                   |
| --------------------------- | ------ | ------------------------------------------------------ |
| 模块骨架注册踩坑            | Day 1  | 参照 `docs/problem.md` 中 `maven-compiler-plugin` 经验 |
| 乐观锁调试                  | Day 2  | 先用单线程走通，再加并发测试                           |
| 敏感词词库质量              | Day 3  | 先内置 20+ 常见词，后续运营补充                         |
| 工单状态流转漏分支          | Day 4  | 状态机枚举集中定义可跳转方法，防止散落判断              |
| 前端 Vant 组件兼容性        | Day 6  | 优先用 Vant 4 稳定版，避免 beta 特性                   |
| 图片上传大小/格式校验       | Day 5/6| 前端+后端双重校验，参照现有上传组件                    |
