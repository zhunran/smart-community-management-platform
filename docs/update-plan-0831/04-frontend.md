# 前端改造计划（admin-web + owner-web）

---

## 一、admin-web（管理端，Vue3 + Element Plus）

### 1.1 新增路由与菜单

```
社区管理（一级菜单）
  ├─ 活动管理     /community/activity
  ├─ 论坛管理     /community/forum        （帖子审核/置顶/加精）
  ├─ 评论管理     /community/comment
  └─ 投票管理     /community/vote         （二期）

服务管理（一级菜单）
  ├─ 报修工单     /service/repair
  ├─ 场地管理     /service/venue          （二期）
  └─ 访客记录     /service/visitor        （二期）
```

菜单数据若来自后端权限表，需同步插入菜单 SQL；若为前端静态路由，直接在 `router/index.ts` 添加并配 `meta.title/icon`。

### 1.2 页面清单

| 页面             | 核心组件          | 要点                                                                                              |
| ---------------- | ----------------- | ------------------------------------------------------------------------------------------------- |
| 活动管理         | 表格 + 抽屉表单   | 状态 Tag 颜色映射；富文本用现有 wangeditor/quill（与公告一致）；报名人数列点击弹详情              |
| 论坛管理         | 表格 + 审核弹窗   | 待审核 Tab 默认；驳回必填原因；置顶/加精开关列                                                    |
| 评论管理         | 表格              | 按帖子筛选；删除二次确认                                                                          |
| 报修工单         | 列表 + 详情抽屉   | **状态流转按钮按当前态渲染**（待审核→通过/驳回；待派单→指派）；超时行红色标记；图片 el-image 预览 |
| 工单统计         | 图表              | 复用 ECharts 模式（同缴费趋势页）：状态分布饼图 + 近 7 日新增折线                                 |
| 场地管理（二期） | 表格 + 表单       | 开放时间/粒度/上限配置                                                                            |
| 访客记录（二期） | 表格              | 有效期状态筛选；核销入口                                                                          |
| 投票管理（二期） | 表单 + 结果条形图 | 选项动态增删                                                                                      |

### 1.3 通用改动

- `api/` 目录新增 `community.ts`、`service.ts` 请求封装（复用 `utils/request.ts`，自动携带 Cookie + 401 静默刷新）
- 图片上传：复用现有上传组件；新建公共上传接口 `/api/admin/common/upload`（如已有则直接用）
- 时间选择：`el-date-picker` datetime range 模式

## 二、owner-web（业主端，Vue3 + Vant 移动适配）

### 2.1 底部导航调整

现有 Tab 若为「首页/账单/我的」结构，改为：

```
首页   社区   服务   账单   我的
```

"服务" Tab 内含报修入口（一期）+ 场地预约、访客邀请（二期），作为便民服务聚合入口。若现有 Tab 已超 4 个，将"社区"改为首页宫格入口 + 首页信息流卡片方式呈现。

### 2.2 页面清单

| 页面                  | 路由                    | 组件要点                                                               |
| --------------------- | ----------------------- | ---------------------------------------------------------------------- |
| 社区首页              | /community              | 顶部 Tab（活动/论坛）；活动卡片列表（封面图+报名进度条）               |
| 活动详情              | /community/activity/:id | 富文本渲染；报名按钮状态（未开始/报名中/已满/已报名→取消）；我的报名态 |
| 论坛列表              | /community/forum        | 分类横向滚动筛选；置顶标识；下拉刷新 + 上拉加载（vant List）           |
| 发帖页                | /community/forum/post   | 标题/内容/分类/图片（vant Uploader 多图）                              |
| 帖子详情              | /community/forum/:id    | 图片预览（vant ImagePreview）；点赞心形动画；底部评论输入框            |
| 投票列表/详情（二期） | /community/vote         | 单选/多选提交；结果条形占比                                            |
| 报修入口              | /service/repair         | 分类宫格选择（水电/门窗/电梯/公共设施）                                |
| 提交报修              | /service/repair/create  | 表单 + 照片；紧急程度选择                                              |
| 我的工单              | /service/repair/mine    | 状态步骤条（vant Steps 8 态映射 5 步展示）；详情含处理进度时间线       |

**8 态 → 5 步映射规则**：

| 后端状态          | 步骤条展示                                          | 步骤序号                                |
| ----------------- | --------------------------------------------------- | --------------------------------------- |
| 0待审核 / 1待派单 | 已提交                                              | 1                                       |
| 2已派单           | 待处理                                              | 2                                       |
| 3维修中           | 处理中                                              | 3                                       |
| 4已完成           | 待评价                                              | 4                                       |
| 5已评价           | 已完成                                              | 5                                       |
| 6已驳回 / 7已取消 | 对应展示"已驳回"/"已取消"（非步骤条，独立状态标签） | -                                       |
| 工单评价          | /service/repair/:id/rate                            | 星级（vant Rate）+ 评语                 |
| 场地预约（二期）  | /service/venue                                      | 场地列表 → 日历选时段（占用置灰）→ 确认 |
| 访客邀请（二期）  | /service/visitor                                    | 表单 + 二维码弹层（qrcode 库）+ 分享    |

### 2.3 技术要点

- **SSE/长轮询不引入**：论坛新回复提示走下拉刷新，不做实时推送
- **图片懒加载**：列表用 vant Lazyload
- **骨架屏**：活动/论坛列表首屏
- 复用 `utils/request.ts`（httpOnly Cookie 自动携带，无需改动）
- AI 客服入口保持在首页悬浮，不受影响
- **二期依赖**：访客通行码页面需 `npm install qrcode`（二维码渲染库），二期开发时添加
