# 上宫苑 · 社区数据采集清单（中型规模）

> 用途：社区「上宫苑」的基础信息采集，供 RAG / 社区规章 PDF 生成及物业管理平台数据初始化使用。
> 数据规模：中型社区（12 栋住宅、约 1296 户、约 500 个车位）。
> 对应数据库脚本：`sql/sample-data-medium-scale.sql`。

| 住宅楼栋       | 12 栋                                   |
| 总户数（住宅） | 约 1296 户                              |
| 常住人口       | 约 3800 ~ 4200 人                       |

| 入住率分布     | 自住约 70%、出租约 20%、空置/装修约 10% |

## 一、基础概况

- **社区名称**：上宫苑
- **所在地**：杭州市西湖区
- **分期情况**：
  - 一期：1~3号楼、7栋、9号楼（18 层）
  - 二期：4~6号楼（30 层）
  - 三期：10~13号楼（18/30 层）
- **楼栋结构**：楼栋 → 单元 → 房屋 三级层级
- **梯户比**：18 层楼两梯四户；30 层楼三梯六户
- **户型面积**：约 90 ~ 140 ㎡（顶层复式/大平层更大）
- **商铺分布**（低优先级）：临街商铺约 20 间，集中于一期沿街（如 1号楼 1 单元商铺），商业用房物业费单价与住宅不同。

### 缴纳方式

- 水电费随物业费按月合并出账，支持：支付宝、微信、银行卡、现金、转账。
- 缴费渠道：业主端 App / 小程序、物业服务中心前台。
- 抄表方式：水表、电表按月抄表（手动/远程/业主自报）。

### 滞纳金起算规则（高优先级）

- 逾期定义：账单超过缴费截止日（due_date）即视为逾期。
- 宽限期：逾期后 30 天内为宽限期（`late.fee.days = 30`），此期间不产生滞纳金，账单状态保持「未缴/部分缴纳」。
- 起算：从逾期第 31 天起按日计息，并将账单标记为「逾期（OVERDUE）」状态。
- 公式：滞纳金 = 未缴金额 × 0.1%/日 ×（逾期天数 − 30）。
- 封顶：累计滞纳金不超过未缴本金（100% 封顶）。
- 执行：XXL-Job `overdueScanJob` 每日 08:00 扫描重算（幂等覆盖），结果写入 `t_bill.late_fee` 字段（非明细项）。
- 调整：修改 `t_sys_config` 的 `late.fee.rate`（日利率）、`late.fee.days`（宽限期天数）即可，下次任务自动生效。

### 费用项计费方式（中优先级）

- 结构：一张账单（t_bill）由多条费用明细（t_bill_item）组成；每个启用（status=1）的费用项独立计费为一条明细，合并到同一张账单总额，不拆成多张账单。
- 计费方式（calc_type）：

  | calc_type | 方式     | 示例                   | 公式                                 |
  | --------- | -------- | ---------------------- | ------------------------------------ |
  | 1         | 按面积   | 物业费、安保费         | 面积 × 单价 × 周期                   |
  | 2         | 按户     | 垃圾清运费、电梯维护费 | 单价 × 周期                          |
  | 3         | 按用量   | 水费、电费             | 用量 × 单价（无抄表数据按 100 预估） |
  | 4         | 固定金额 | 停车费                 | 单价                                 |

- 新增费用项：在 `t_fee_item` 新增并启用后，下一账期生成账单时自动参与计费。
- 特殊点：
  - 金额 ≤ 0 的费用项会被跳过（如「滞纳金」单价为 0，不生成明细，改由定时任务写入 late_fee）。
  - 支持「分项缴费」，可对单条明细单独缴费。
  - 停车费（fee_item_id=4）可在账单列表单独筛选。

## 三、装修费用与规定（高优先级）

### 装修费用

| 项目           | 标准       | 说明                   |
| -------------- | ---------- | ---------------------- |
| 装修押金       | 3000 元/户 | 装修验收合格后无息退还 |
| 装修管理费     | 5 元/㎡    | 按建筑面积一次性收取   |
| 装修垃圾清运费 | 8 元/㎡    | 一次性收取，集中清运   |

### 装修时间限制

- 允许施工时间：工作日 8:00 ~ 12:00、14:00 ~ 18:00。
- 禁止施工时间：工作日 12:00 ~ 14:00、18:00 以后；周末及法定节假日全天禁止噪音施工。

### 禁止事项

- 禁止拆改承重墙、梁、柱等承重结构。
- 禁止改变建筑外立面、封闭消防通道及疏散通道。
- 禁止擅自改动燃气、给排水、强弱电主管道。
- 禁止高空抛物及向楼下倾倒装修垃圾。

## 五、设施与资源

- **停车资源**：
  - 地下一层（B1）：A~H 区，标准车位 + 充电桩车位

- **应急集合点**：社区中心广场及各楼栋南侧空地（疏散后集合）。

## 六、居住管理规定（中优先级）

### 宠物管理

- 遛犬须牵绳、佩戴犬牌，及时清理粪便。
- 禁止饲养烈性犬、大型犬（以当地禁养目录为准）。
- 禁止在公共区域（楼道、电梯、绿地）放养宠物。

### 封阳台 / 空调外机

- 封阳台须使用统一材质与颜色（灰色铝合金 + 同色玻璃），施工前须向物业报备审批。
- 空调外机须安装于指定机位，禁止悬挂外墙、禁止冷凝水滴落影响他人。
